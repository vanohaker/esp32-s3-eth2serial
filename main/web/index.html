Вход

Состояние

Терминал использует serial эксклюзивно. Для отправки файла сначала закройте SSH/Telnet-соединение.

XMODEM и YMODEM реализованы. ZMODEM, BREAK и XON/XOFF — в следующих версиях.

Сеть

VLAN 0 — без тегирования. VLAN 1–4094 — только указанный тег, MTU 1496. Режим VLAN требует испытаний на плате.

Serial

UART1: TX GPIO16, RX GPIO17. RTS/CTS отсутствует. MAX3232 подключается TTL-стороной к ESP32, RS-232-стороной к целевому устройству.

Пользователи

Все включённые пользователи — администраторы. До 8 пользователей, один публичный SSH-ключ на пользователя.

ИмяВключёнДействия

Пустой пароль сохраняет существующий. Пустое поле ключа удаляет ключ. После изменения пользователей потребуется повторный вход.

Файлы microSD

Файлы в корневом каталоге. Имена: латинские буквы, цифры, точка, дефис и подчёркивание; до 60 символов. Размер загрузки — до 64 МиБ. Существующие файлы не перезаписываются.

ИмяБайтДействия

Сначала запустите приём на целевом устройстве, затем закройте консоль и начните передачу. Протокол должен поддерживаться приёмником.

Удаляет все файлы карты. Настройки донгла сохраняются. Аппаратную неисправность карты форматирование не устраняет.

Почта

Прототип: SMTP без авторизации и без TLS для собственного сервера. Письмо отправляется один раз после старта с повторами при недоступности сервера. Пароли и ключи в письмо не включаются.

Система

Настройки сети, serial, протоколов и почты применяются после перезагрузки.

Сертификат HTTPS

Изначально используется индивидуальный самоподписанный сертификат. Можно загрузить сертификат PEM и соответствующий приватный ключ PEM без пароля. Ключ HTTPS отличается от публичных ключей пользователей SSH.

Заводской сброс

Во время работы удерживайте BOOT 10 секунд, затем отпустите. Готовность сообщается в USB-консоли. Настройки, пользователи и ключи будут удалены, microSD сохранится. После сброса имя и пароль: admin / admin. При активной файловой операции сброс отклоняется. Не удерживайте BOOT во время включения питания или RESET: это вход в ROM-загрузчик.
